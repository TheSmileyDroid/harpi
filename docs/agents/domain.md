# Domain docs

Where this repo keeps its vocabulary and the decisions behind it.

## Read these

- `docs/agents/architecture.md` — the glossary and where code lives. Its vocabulary is
  binding for code, docs, issues and test names.
- `docs/adr/` — the decisions. Read the ADRs that touch the area before changing it.

There is no `CONTEXT.md` and no `CONTEXT-MAP.md`. Do not create them: the glossary lives
in `architecture.md`, next to the layout it describes.

If your output contradicts an ADR, say so explicitly instead of overriding it silently.
